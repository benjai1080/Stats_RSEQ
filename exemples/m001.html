Glossaire

Un seul match, c'est peu : les stats « sur le terrain » d'un joueur qui a joué quelques minutes reposent sur une poignée de possessions. Survoler un titre de colonne affiche sa définition ; cliquer trie le tableau.

+/-
Points marqués moins points accordés par l'équipe pendant que le joueur est sur le terrain.
Possession
Comptée à chaque changement de main du ballon : panier réussi, rebond défensif, balle perdue, dernier lancer franc réussi. Un rebond offensif prolonge la possession.
ORtg / DRtg
Points marqués / accordés par 100 possessions. Net = ORtg − DRtg.
On-Off
Net de l'équipe avec le joueur sur le terrain moins Net quand il est sur le banc.
eFG%
(Paniers + 0,5 × paniers à 3 pts) / tirs tentés : un panier à 3 vaut 1,5 panier à 2.
TS%
Points / (2 × (tirs + 0,44 × lancers francs tentés)) : efficacité qui compte aussi les LF.
USG%
(Tirs + 0,44 × LF + pertes) du joueur / les mêmes actions de l'équipe pendant qu'il joue.
PD%
Passes décisives / paniers des coéquipiers pendant qu'il joue.
RO% / RD%
Rebonds captés / rebonds disponibles pendant qu'il joue.
INT% / CTR%
Interceptions par possession adverse ; contres par tir de 2 points adverse.
GmSc
Game Score de Hollinger : PTS + 0,4 PR − 0,7 TT − 0,4 LF ratés + 0,7 RO + 0,3 RD + INT + 0,7 PD + 0,7 CTR − 0,4 F − BP.
EVAL
Évaluation FIBA : PTS + REB + PD + INT + CTR − tirs ratés − LF ratés − BP.
Rythme
Possessions par équipe ramenées à 40 minutes.
